# Casos atendidos

Perguntas que valeram guardar (o Julio decide o que entra). Sem nome de aluno.

Formato:

```
## AAAA-MM-DD — título curto
- Pergunta: o que chegou (robô real ou simulador, qual competição).
- Causa: o que era.
- Resposta: o que resolveu.
- Onde: arquivos/seções que ajudaram.
```
