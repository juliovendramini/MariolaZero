# `BNO085` — IMU de 9 eixos com fusão de sensores (I2C)

Arquivo: `libs/bno085.py` · `from bno085 import BNO085`

## Para que serve

O BNO085 tem acelerômetro, giroscópio e magnetômetro e **um processador que junta os três**
(fusão), entregando a orientação pronta em quaternion. É uma alternativa à placa do giroscópio na
serial, ligada num conector **I2C** do Mariola:

* rumo (yaw), arfagem (pitch) e rolagem (roll) em graus;
* aceleração (m/s²), velocidade angular (rad/s), campo magnético (µT);
* aceleração linear (sem a gravidade) e o vetor da gravidade, se habilitar.

## Como funciona

A lib implementa uma versão simplificada do protocolo SHTP/SH-2: reseta o sensor, confere o ID e
habilita os relatórios padrão (vetor de rotação, acelerômetro, giroscópio e magnetômetro a 50 Hz).
O sensor vai **acumulando pacotes**; cada `le_valores()` processa os que chegaram e guarda o mais
recente de cada tipo.

## Métodos

### `BNO085(porta_mux, endereco=None)`
```python
imu = BNO085(Portas.I2C2)          # endereço 0x4A (0x4B se o pino ADR estiver em alto)
```
Leva ~1 s (reset do sensor). `OSError` se não responder.

### `le_valores(timeout_ms=50, max_pacotes=20)` → `dict`
Processa os pacotes pendentes (no máximo `timeout_ms` e `max_pacotes`) e devolve:

```python
{'aceleracao': (x, y, z), 'giroscopio': (x, y, z), 'magnetometro': (x, y, z),
 'aceleracao_linear': (x, y, z), 'gravidade': (x, y, z),
 'quaternion': (i, j, k, real), 'euler': (yaw, pitch, roll)}
```

* **Quando usar:** no laço, de preferência com frequência (se ficar muito tempo sem ler, os
  pacotes se acumulam e você lê valores atrasados).

### `euler()` → `(yaw, pitch, roll)` em graus, do último quaternion
O yaw vai de -180 a 180 (dá a volta). Para girar, trate a passagem por ±180 (ex.: erro =
`(alvo - yaw + 180) % 360 - 180`).

### `habilita_relatorio(id_relatorio, intervalo_us=None)`
Liga outro relatório: `REPORT_ACELERACAO_LINEAR`, `REPORT_GRAVIDADE`,
`REPORT_VETOR_ROTACAO_JOGO` (rotação sem magnetômetro — **melhor dentro de um prédio cheio de
ferro e motores**, pois não é puxada pelo campo magnético), etc. Intervalo em µs (20000 = 50 Hz).

* **Cuidado:** relatórios demais ou rápidos demais enchem o buffer mais rápido do que a lib
  consegue ler através do mux.

### `recover()` · `select_channel()` · `close_channel()`
Recuperar o sensor depois de erro no barramento; selecionar/fechar o canal do mux.

## Giroscópio serial x BNO085

| | `Giroscopio` (serial) | `BNO085` (I2C) |
|---|---|---|
| Z/yaw | acumula (720° = 2 voltas) | -180 a 180 |
| Leitura | thread automática | você chama `le_valores()` |
| Extras | — | aceleração, magnetômetro, gravidade |

## No simulador

**Não é emulado.** Para usar o mesmo programa nos dois, use o `Giroscopio` no simulador ou
esconda o sensor atrás de uma função sua (`def rumo(): ...`).
