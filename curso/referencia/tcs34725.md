# `TCS34725` — sensor de cor avulso (I2C)

Arquivo: `libs/tcs34725.py` · `from tcs34725 import TCS34725`

## Para que serve

Um sensor de cor TCS34725 (o mesmo chip dos três que ficam no Pro1616), ligado **direto num
conector I2C** do Mariola. Como ele não fica preso no sensor de linha, você o coloca onde quiser:

* **Área de resgate:** sensores **horizontais** na frente e atrás do robô, na altura das paredes,
  para conferir a **cor do triângulo** (verde/vermelho) antes de soltar as vítimas, ou a cor da
  vítima na garra (prata = viva, preta = morta).
* Um sensor de piso extra (ex.: atrás do robô).

## Como funciona

* Endereço fixo 0x29: um por conector I2C (o mux separa).
* A lib liga o sensor com **ganho 4x** e tempo de integração `ATIME = 0xC0`, que dá **~154 ms por
  medida** (64 ciclos × 2,4 ms; o comentário no código diz ~60 ms, mas a conta dá 154). Ler mais
  rápido que isso devolve o mesmo valor.
* Devolve os valores **crus** de 16 bits (0 a 65535), sem calibração. O LED branco do módulo
  ilumina o alvo, então a leitura cai muito com a distância: o que vale é a **proporção** entre
  R, G e B.

## Métodos

### `TCS34725(porta_mux)`
```python
tcs_tras = TCS34725(Portas.I2C7)
```
Liga o sensor no canal indicado (`ValueError` se o canal for inválido; `OSError` se não responder).

### `le_valores()` → `(r, g, b, c)`
Seleciona o canal e lê. `c` (clear) é a luz total.

```python
r, g, b, c = tcs_tras.le_valores()
if c > 50 and g > 1.3 * r and g > 1.1 * b:
    print('verde')
elif c > 50 and r > 1.6 * g and r > 1.6 * b:
    print('vermelho')
```

* **Quando usar:** sempre que precisar da cor de algo que não está no chão embaixo do sensor de
  linha.
* **Dica:** classifique pela proporção (`r/c`, `g/c`, `b/c`) e só aceite quando `c` passar de um
  mínimo (perto o bastante).
* **Junto com VL53:** `le_valores()` não espera a medida (só lê os registradores), então é ótimo
  para ler **no meio** da espera dos VL53: `solicita_leitura()` em todos, `le_valores()` nos TCS,
  `leitura_mm()` em todos.
* **Cuidado — threads:** o TCS divide o barramento e o multiplexador com os VL53. Leia todos os
  sensores I2C numa thread só ([módulo 7, item 7.3](../07-sensores-de-distancia.md)).

### Métodos internos
`_select_channel()`, `_read_tcs_id()` (deve dar 0x44 ou 0x10), `_read_word(reg)`.

## No simulador

`tcs_i2c` no `robo_4x4.json` (frente I2C6, trás I2C7, altura e direção). Ele lê a cor do que está
na frente na altura dele (parede, triângulo, vítima), mais fraco com a distância.
